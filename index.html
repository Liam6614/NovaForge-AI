Diagnostic


  

  
Connexion IA

  
Aucune API d'intelligence artificielle n'est encore connectée. Une connexion sécurisée à un serveur sera nécessaire pour activer la génération réelle par IA.

 






 
Aide

 
Comment utiliser NovaForge AI ?

 

  
Créer un projet

  
Écris ton idée sur l'accueil ou ouvre un outil de création. Tu peux ensuite enregistrer ton projet.

  

  
Utiliser Code Studio

  
Modifie les fichiers HTML, CSS et JavaScript. Appuie sur Aperçu pour voir le résultat de ton site.

  

  
Sauvegarder

  
Les projets et fichiers sont enregistrés dans le stockage local du navigateur utilisé.

  

  
Intelligence artificielle

  
Les outils de création sont actuellement des espaces de préparation. Une API sera nécessaire pour générer automatiquement des contenus avec une IA.
